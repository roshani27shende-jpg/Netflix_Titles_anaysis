# Netflix Movies Analysis

## Project Overview
This project analyzes Netflix Movies and TV Shows data to discover content trends, ratings, genres, and release patterns.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Key Insights
- Movies vs TV Shows distribution
- Content ratings analysis
- Release year trends
- Genre analysis
- Country-wise content distribution

## Dataset
Netflix Movies and TV Shows Dataset
